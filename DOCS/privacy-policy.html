Privacy Policy

Last updated: April 2026

UnmixAudio ("we", "the extension") is committed to protecting your privacy. This policy explains exactly what data is processed, where, and for how long.

The short version:
  • BPM & Key detection: 100% local — no audio leaves your device.
  • Track export: audio is NEVER STORED — processed in server memory only, permanently deleted within seconds.
  • No accounts, no tracking, no analytics, no ads.

What We Process and How

  • BPM & Key analysis (real-time, 100% local): All tempo and musical key detection is performed entirely on your device inside the extension's sandboxed environment, using Essentia WASM and TensorFlow.js models bundled with the extension. No audio data is sent to any server for this analysis. No network connection is required for BPM or Key detection.
  • Track Export (source separation): Only when you explicitly use the Track Export feature, your recorded audio is sent to our processing server over an encrypted HTTPS connection. The file is loaded into memory, processed by the source separation model (Demucs), and the resulting tracks are returned to your browser. The original file and all intermediate data are deleted immediately and permanently upon completion. No copy is retained on the server under any circumstances.
  • Analysis results (BPM, Key, library): Stored only in chrome.storage.local on your own device. Never transmitted to any server or third party.

What We Never Do

  • We never store audio recordings or audio data on any server.
  • We never log or retain any user audio in any form.
  • We never sell, share, or transmit your data to third parties.
  • We never use analytics, advertising trackers, or fingerprinting.
  • We never require account creation or collect personal information.

Server Infrastructure

Audio processing is performed on a server hosted by Railway (railway.app). All connections are encrypted (HTTPS/WSS). The server processes audio exclusively in memory and retains no data after each request completes.

User Responsibility

UnmixAudio is an audio analysis utility. Users are solely responsible for ensuring they have the legal right to capture, analyze, or export any audio content processed through this extension.
