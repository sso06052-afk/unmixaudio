# 🚀 Chrome Web Store 배포 가이드

Audio Analyzer 익스텐션을 다 만들었다면 심사를 거쳐 전 세계 사용자들이 쓸 수 있도록 스토어에 출시할 수 있습니다.

## 1. 배포 패키지 파일 준비
로컬 폴더에서 심사에 필요한 실제 확장 프로그램 파일만 모아서 `.zip` 파일로 압축합니다.
- **포함할 항목**: `manifest.json`, `background.js`, `audio-worklet-processor.js`, `content-script.js`, `offscreen.html`, `offscreen.js`, `popup.html`, `popup.js`, `icons/`, `lib/` 등 실제 런타임 파일.
- **제외할 항목**: 소스 관리에 쓰인 `.agents`, `DOCS`, `test` 폴더, OS 메타데이터 파일 등.

## 2. 아이콘 및 스토어 등록용 이미지 에셋
Chrome Web Store 정보를 꾸미기 위해 다음 이미지들이 필수 또는 적극 권장됩니다:
1. **스토어 아이콘 (128x128 픽셀)**: 기존 프로젝트의 `icons/icon128.png` 를 활용할 수 있습니다. (투명 배경 적극 권장)
2. **스크린샷 (1개 이상 필수)**: `1280x800` 또는 `640x400` 픽셀 크기. 팝업이 동작중인 화면을 예쁘게 캡처해서 올집니다.
3. **프로모션 마키 이미지 (Marquee, 440x280 픽셀)**: 스토어에서 사용자의 눈길을 끌 수 있는 대표 썸네일로 활용됩니다.

## 3. 개발자 계정 등록 & 결제
1. [Chrome Web Store 개발자 대시보드](https://chrome.google.com/webstore/devconsole) 에 접속합니다.
2. 개발자 계정을 활성화하기 위해 최초 1회 **$5의 등록비**를 결제해야 합니다. (이후 평생 무료로 등록 가능)

## 4. 새 항목 추가 및 업로드
1. 대시보드 우측 상단의 **[새 항목 추가 (Add new item)]** 버튼을 클릭합니다.
2. 1단계에서 만든 `.zip` 파일을 화면에 업로드합니다.
3. **스토어 정보(Store Listing) 작성**:
   - **이름/요약**: 익스텐션 이름과 주요 기능을 핵심만 기재합니다 (예: "Real-time BPM & Key detector for any streaming audio").
   - **설명**: 사용 대상(DJ, 댄서, 음악 애호가 등)과 기능(Mel Spectral Flux 및 CQT HPCP 등 정확도를 강조)을 어필합니다.
   - **카테고리**: *생산성(Productivity)* 또는 *개발자 도구(Developer Tools)* 항목에 올립니다.

## 5. 개인정보 처리방침 (Privacy Policy) 제출 🚨
Manifest V3부터는 강력한 보안/개인정보 처리 심사가 포함됩니다:
- Audio Analyzer는 `tabCapture` 권한으로 민감할 수 있는 탭 오디오를 캡처하지만, 외부 서버(네트워크)로 오디오를 전송하지 않고 **100% 브라우저 메모리 안의 로컬 오디오 스레드(AudioWorklet)에서만 처리**하므로 프라이버시가 완벽히 보장됩니다.
- "개인정보보호 처리방침 URL(Privacy Policy URL)" 입력란에 Notion이나 Github Pages 등으로 임시 페이지를 만들고, *"본 확장 프로그램은 오디오 데이터를 캡처하지만, 오직 로컬 분석 용도로 브라우저 안에서만 처리하며 어떠한 외부 서버로도 전송하거나 수집하지 않습니다."* 라는 내용을 명시한 뒤 해당 링크를 제출해야 심사를 무사히 통과합니다.

## 6. 심사 제출 및 대기
- 모든 정보 입력이 완료되었다면 우측 상단의 **[심사 제출(Submit for review)]**을 클릭합니다.
- 본 확장 프로그램은 `tabCapture` 같은 강력한 접근 권한을 포함하고 있어 로봇 자동 심사를 넘어 수동 리뷰가 진행될 확률이 높습니다 (보통 2영업일 ~ 5영업일 소요).
- 심사가 끝나면 상태가 "게시됨(Published)"으로 전환되며 URL을 지인들에게 공유할 수 있게 됩니다!
