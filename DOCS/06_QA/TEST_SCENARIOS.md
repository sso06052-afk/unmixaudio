## BPM 테스트 시나리오

| 장르 | 예상 BPM 범위 | 특이사항 | 통과 기준 |
|---|---|---|---|
| Trap | 130-160 | 808 베이스, 16분음표 하이햇 | ±3 BPM 이내 |
| Drill | 140-150 | 롤링 하이햇, 싱코페이션 | ±3 BPM 이내 |
| House | 120-130 | Four-on-the-floor 킥 | ±2 BPM 이내 |
| Hip-Hop | 80-100 | 느린 템포, 옥타브 에러 위험 | ±3 BPM 이내 |
| 발라드 | 60-80 | 옥타브 더블링 위험 | ±3 BPM 이내 |

## Key 테스트 시나리오

| 케이스 | 테스트 목적 | 통과 기준 |
|---|---|---|
| C Major (명확한 화음) | 기본 Major 감지 | 정확히 C Major |
| A Minor (C Major 상대조) | 상대조 모호성 해소 | 베이스음으로 올바른 선택 |
| Dorian 모드 | 5가지 모드 감지 | Dorian 반환 |
| 808 Trap (베이스 과다) | 노이즈 게이팅 | 808에 오염 안 됨 |
