# 🛑 WORKFLOW: Spec-Gate ("문서 먼저, 코드는 나중에")

사용자가 "기능을 구현해줘"라고 요청할 때, AI는 **절대 코드를 바로 작성하면 안 됩니다**.

## 동작 절차
1. **Gate 1 (기획/디자인 확인)**
   - `DOCS/01_Product/PRD.md`에 요구사항이 있는지 확인.
   - UI 작업인 경우 `DOCS/02_Design/UI_UX_GUIDELINES.md`에 디자인이 정의되어 있는지 확인.
2. **Gate 2 (기술 명세 확인)**
   - API나 로직 작업인 경우 `DOCS/04_Technical_Spec/` 하위의 관련 문서가 작성되어 있는지 확인.
3. **결과 판정**
   - **통과 (✅)**: 모든 필수 문서가 존재하고 비어있지 않음. -> 코딩 시작.
   - **실패 (❌)**: 문서가 없거나 비어있음. -> 코딩 거부 및 문서 작성 프롬프트 유도.
     > `⛔ [SPEC-GATE 실패] 구현 불가. /DOCS/04_Technical_Spec/ALGORITHM_SPEC.md 문서가 비어있습니다. 해당 명세 먼저 작성할까요?`

※ 예외: 사용자가 명시적으로 핫픽스(hotfix)나 실험(prototype)을 요청한 경우 `[SPEC-GATE 우회]` 로그를 남기고 진행합니다.
